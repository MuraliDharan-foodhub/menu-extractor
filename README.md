# AI Menu Extractor

A production-ready tool that accepts a menu image, uses Google Cloud Vision API to extract its contents, renders an interactive and editable preview, and pushes the finalized menu to the backend API.

## Features (Coming Soon)
- 📷 Image upload with drag-and-drop
- 🤖 AI-powered text extraction using Google Cloud Vision
- ✏️ Interactive menu editor
- 🔄 Undo/redo support
- 📱 Mobile responsive design

## Tech Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Google Cloud Vision API
